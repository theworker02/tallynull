# tallynull

Tally timestamps and null durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/tallynull/

## Install / run

```bash
git clone https://github.com/theworker02/tallynull.git
cd tallynull
node src/cli.js
node --test
```
